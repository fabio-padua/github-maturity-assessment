# GitHub Maturity Assessment

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Consultants facilitating assessment sessions with customer stakeholders.

## Product Purpose

Collect customer answers about GitHub Enterprise and GitHub Copilot adoption and turn them into an understandable maturity dashboard and practical modernization recommendations.

## Operating Context

The confirmed first version is a local-first web application for consultant-led sessions, with saved assessments and exportable reports. The private source repository is `fabio-padua/github-maturity-assessment`.

## Capabilities and Constraints

Assess governance, DevSecOps, delivery, developer experience, Copilot, and organizational readiness. Explain score calculations, distinguish missing evidence from low maturity, and provide recommendations and a 30/60/90-day roadmap. The reference proposes Optimize + Copilot, Hybrid, Migrate, and Secure DevOps paths.

No hosted customer accounts, backend, or automatic GitHub data collection in the first version. Answers stay in the browser unless explicitly exported. Browser storage is not a secure enterprise customer-record system. Pricing and productivity figures must be customer-provided assumptions, never invented current prices or guaranteed savings.

The user subsequently requested a public Azure demonstration in the MCAPS subscription, preferring Container Apps or App Service, with no assessment persistence. The hosted demo uses browser memory only and clears on refresh; the original local consultant mode remains available. East US 2 and public access with fictional/session-only data were confirmed.

## Brand Commitments

The supplied modernization-assessment image guides information architecture: current state, readiness, deliverables, and a recommended journey. Preserve its navy, blue, purple, and teal visual vocabulary without suggesting official GitHub certification.

## Evidence on Hand

A user-provided assessment reference image. No customer data or validated benchmark dataset has been supplied. Any sample assessment must be conspicuously synthetic.

## Product Principles

- Make every maturity score traceable to answers.
- Treat incomplete and unknown answers honestly.
- Connect gaps to concrete next actions.
- Keep each customer's assessment distinct and exportable.
